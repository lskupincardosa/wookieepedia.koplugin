# Changelog

## 0.2.0 (first public release)

- **Portrait** button: the article's main picture (character, species, ship …) full screen, saved for offline use.
- **Species button** on character articles: shows the species' picture straight away.
- Release zip built by `tools/package.sh`. Requests identify the plugin by its project URL.

## 0.1 (not released)

- Lookup from the selection popup, the dictionary popup and the search menu, with redirects, disambiguation and search fallback.
- Plain-text intros and full articles, saved for offline use.
- Spoiler shield: first-paragraph intros, and full-article paragraphs hidden by the High Republic reading order.
- Location line and galaxy map (galaxy, close-up and optional atlas views) for planets.
